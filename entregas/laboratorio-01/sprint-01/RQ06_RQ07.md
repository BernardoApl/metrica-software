# RQ06 e RQ07

Foram adicionadas as metricas das RQs atribuidas:

- **RQ06:** calcular a razao entre issues fechadas e total de issues.
- **RQ07:** agrupar por linguagem primaria os resultados de RQ02, RQ03 e RQ04.

Arquivos principais:

- `codigo-fonte/analise/rq06_issues.py`
- `codigo-fonte/analise/rq07_por_linguagem.py`
- `codigo-fonte/consulta-graphql/consulta.py`
- `codigo-fonte/coleta/coleta_repositorios.py`

A RQ06 usa `issues.totalCount` e `issuesFechadas.totalCount`.
A RQ07 usa a linguagem primaria como agrupamento e resume PRs aceitos, releases e dias desde a ultima atualizacao.

## RQ06 concluida

Formula: `issuesFechadas.totalCount / issues.totalCount`. Quando o repositorio nao possui issues, a razao fica nula e ele recebe o status `sem_issues`.

Arquivos desta etapa:

- `codigo-fonte/coleta/executar_coleta_rq06.py`
- `codigo-fonte/testes/test_rq06.py`
- `codigo-fonte/testes/validar_amostra_rq06.py`

Testes offline:

```powershell
python -m unittest discover -s codigo-fonte/testes -p "test_rq06.py" -v
```

Validacao com uma amostra de oito repositorios:

```powershell
python codigo-fonte/testes/validar_amostra_rq06.py --quantidade 8
```

Coleta completa em uma unica requisicao GraphQL:

```powershell
python codigo-fonte/coleta/executar_coleta_rq06.py --quantidade 100
```

A validacao confere quantidade, duplicatas, ordem por estrelas, valores brutos da API e a formula da RQ06.

## Resultado da coleta da RQ06

Coleta realizada em 12/08/2026, com 100 repositorios em uma unica requisicao GraphQL:

- 100 repositorios retornados, sem duplicatas;
- 89 repositorios com issues e 11 sem issues;
- razao media de issues fechadas: `0.8341`;
- razao mediana: `0.9261`;
- razao minima: `0.1337`;
- razao maxima: `1.0`.

Os dados completos estao em `dados/lab01s01_rq06.json`.

## RQ07 concluida

A RQ07 divide por linguagem primaria os resultados de:

- RQ02: total de pull requests aceitos;
- RQ03: total de releases;
- RQ04: dias desde a ultima atualizacao.

Para cada linguagem sao calculados quantidade de repositorios, media, mediana, minimo e maximo. Repositorios sem linguagem permanecem no grupo `Sem linguagem definida`.

Arquivos desta etapa:

- `codigo-fonte/coleta/executar_coleta_rq07.py`
- `codigo-fonte/testes/test_rq07.py`
- `codigo-fonte/testes/validar_amostra_rq07.py`

Testes offline:

```powershell
python -m unittest discover -s codigo-fonte/testes -p "test_rq07.py" -v
```

Validacao com uma amostra de oito repositorios:

```powershell
python codigo-fonte/testes/validar_amostra_rq07.py --quantidade 8
```

Coleta completa:

```powershell
python codigo-fonte/coleta/executar_coleta_rq07.py --quantidade 100 --tamanho-pagina 10
```

A consulta completa da RQ07 retornou HTTP 502 quando solicitados 100 repositorios de uma vez. Por isso, a requisicao automatica percorre dez paginas de 10 repositorios com o cursor GraphQL, mantendo a ordenacao e completando os mesmos 100 repositorios.

## Resultado da coleta da RQ07

Coleta realizada em 12/08/2026:

- 100 repositorios retornados, sem duplicatas;
- 18 grupos de linguagem;
- Python: 24 repositorios;
- TypeScript: 17 repositorios;
- sem linguagem definida: 13 repositorios;
- JavaScript: 10 repositorios.

Entre os grupos com maior quantidade de repositorios, TypeScript apresentou mediana de 6.981 pull requests aceitos, 116 releases e 0.08 dia desde a ultima atualizacao. Python apresentou medianas de 1.881,5 pull requests, 54 releases e 1.16 dia. JavaScript apresentou medianas de 1.373,5 pull requests, 69 releases e 0.425 dia.

Os repositorios sem linguagem definida apresentaram menor atividade: mediana de 317 pull requests aceitos, nenhuma release e 114.36 dias desde a ultima atualizacao. Os grupos pequenos devem ser interpretados com cuidado, pois possuem poucos repositorios.

Os dados completos estao em `dados/lab01s01_rq07.json`.

## Compatibilidade com a integracao do grupo

A RQ06 diferencia repositorios sem issues de coletas que nao solicitaram os campos de issues. A RQ07 aceita tanto `rq02_pull_requests_aceitos` quanto `total_prs_aceitos`, nome usado pelo script da RQ02.
