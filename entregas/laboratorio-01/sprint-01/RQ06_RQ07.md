# RQ06 e RQ07

Foram adicionadas as metricas das RQs atribuidas:

- **RQ06:** calcular a razao entre issues fechadas e total de issues.
- **RQ07:** agrupar por linguagem primaria os resultados de RQ02, RQ03 e RQ04.

Arquivos principais:

- `codigo-fonte/analise/rq06_issues.py`
- `codigo-fonte/analise/rq07_por_linguagem.py`
- `codigo-fonte/consulta-graphql/consulta.py`
- `codigo-fonte/coleta/coleta_repositorios.py`

A RQ06 usa `issues.totalCount` e `issuesFechadas.totalCount`.
A RQ07 usa a linguagem primaria como agrupamento e resume PRs aceitos, releases e dias desde a ultima atualizacao.

## RQ06 concluida

Formula: `issuesFechadas.totalCount / issues.totalCount`. Quando o repositorio nao possui issues, a razao fica nula e ele recebe o status `sem_issues`.

Arquivos desta etapa:

- `codigo-fonte/coleta/executar_coleta_rq06.py`
- `codigo-fonte/testes/test_rq06.py`
- `codigo-fonte/testes/validar_amostra_rq06.py`

Testes offline:

```powershell
python -m unittest discover -s codigo-fonte/testes -p "test_rq06.py" -v
```

Validacao com uma amostra de oito repositorios:

```powershell
python codigo-fonte/testes/validar_amostra_rq06.py --quantidade 8
```

Coleta completa em uma unica requisicao GraphQL:

```powershell
python codigo-fonte/coleta/executar_coleta_rq06.py --quantidade 100
```

A validacao confere quantidade, duplicatas, ordem por estrelas, valores brutos da API e a formula da RQ06.

## Resultado da coleta da RQ06

Coleta realizada em 12/08/2026, com 100 repositorios em uma unica requisicao GraphQL:

- 100 repositorios retornados, sem duplicatas;
- 89 repositorios com issues e 11 sem issues;
- razao media de issues fechadas: `0.8341`;
- razao mediana: `0.9261`;
- razao minima: `0.1337`;
- razao maxima: `1.0`.

Os dados completos estao em `dados/lab01s01_rq06.json`.
